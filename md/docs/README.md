# LiveMall 设计文档

> 秋招高并发直播电商项目，目标 10w QPS。
> 文档按编号分层，每层独立目录。

## 文档结构

| 编号 | 目录 | 内容 | 定位 |
|------|------|------|------|
| 1 | 架构设计 | 项目概览、技术选型、技术决策清单、全功能清单 | 整体认知 |
| 2 | 模块详细设计 | 各模块完整设计（流程/架构/DB/安全） | 编码依据 |
| 3 | 功能实现细节 | 单功能级实现设计（流程/I-O/关键代码/边界） | 编码指南 |
| 4 | 面试准备 | 面试官拷打问题与回答策略 | 面试应对 |
| 5 | 运维部署 | 环境搭建、Docker Compose、端口规划 | 运维操作 |
| 7 | 杂七杂八 | 行业参考、外围资料 | 扩充阅读 |

## 编码前必读

- 先看 `2-模块详细设计` 下你要写的那个模块
- 统一返回 `Result<T>`（code/message/data）
- 全局异常处理 `@RestControllerAdvice`
- 工具类用 Hutool、Lombok（`@Data` 用于 VO/DTO）

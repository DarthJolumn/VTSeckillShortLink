# 全功能清单

> 所有功能按链路排列，标注所属模块和前置依赖。

---

## 角色权限

| 角色 | 说明 |
|------|------|
| 普通用户（观众） | 看直播、发弹幕、抢购、送礼、看排行 |
| 主播 | 观众权限 + 开播/关播、上架秒杀、管理直播间 |
| 管理员 | 主播权限 + 管理活动、封禁用户、数据查看 |

权限校验方式：`@RequireRole` 注解 + ScopedValue 传角色。

## 一、用户与认证

| # | 功能 | 说明 | 所属模块 | 依赖 |
|---|------|------|---------|------|
| 1 | 注册 | 用户名 + 密码（BCrypt），可选手机号 | user | MySQL |
| 2 | 登录 | 密码登录 → 签发双 Token | user | MySQL + Redis |
| 3 | Token 刷新 | Refresh Token 换 Access Token | user | Redis |
| 4 | 退出登录 | 删除 Refresh Token | user | Redis |
| 5 | 查看已登录设备 | 列出该账号所有在线设备 | user | Redis |
| 6 | 踢设备下线 | 删 Redis Token + WS 推送踢下线 | user + websocket | Redis + WS |
| 7 | 修改用户信息 | 头像/昵称/密码 | user | MySQL |
| 8 | 封禁/解禁账号 | 管理员操作，封禁后所有 Token 失效 | user | MySQL + Redis |

## 二、直播流

| # | 功能 | 说明 | 所属模块 | 依赖 |
|---|------|------|---------|------|
| 9 | 开播 | 主播发起 → 创建直播间记录 → WS 建立 | websocket | Redis + MySQL |
| 10 | 关播 | 主播结束 → 踢出所有观众 → 状态持久化 | websocket | Redis + MySQL |
| 11 | 进直播间 | 观众连接 WS → 加入房间 → 在线数 +1 | websocket | Redis |
| 12 | 离开直播间 | 观众断开 → 在线数 -1 | websocket | Redis |
| 13 | 在线人数统计 | Redis 实时计数，定时同步 MySQL | websocket | Redis + MySQL |
| 14 | 单端观看踢人 | 同一账号新连接 → 旧连接发 KICK | websocket | Redis + WS |
| 15 | 心跳检测 | 客户端 PING 30s → PONG → 60s 超时断开 | websocket | WS |
| 16 | 断线重连 | 客户端指数退避重连 → 服务端补发未读消息 | websocket | WS + Redis |

## 跨模块依赖图（简化）

```
gateway ──→ user（鉴权）
gateway ──→ seckill（路由抢购请求）
seckill ──→ websocket（推秒杀结果）
websocket ──→ leaderboard（送礼加分）
user ──→ websocket（踢设备）
common ──→ 所有模块（ID/签名/上下文）
```

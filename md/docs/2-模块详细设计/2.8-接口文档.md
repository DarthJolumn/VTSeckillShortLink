# 接口文档

> 所有 REST 接口经过 Gateway（8080），返回统一格式 `Result<T>`。WebSocket 直连（8083）。

---

## 一、用户服务（livemall-user）

| 方法 | 路径 | 说明 | 鉴权 | 请求/响应 |
|------|------|------|------|----------|
| POST | `/auth/register` | 注册 | 签名 | `{username, password, phone?}` → `Result` |
| POST | `/auth/login` | 登录 | 签名 | `{username, password}` → `{accessToken, refreshToken, expiresIn}` |
| POST | `/auth/refresh` | 刷新 Token | 签名 | `{refreshToken}` → `{accessToken, expiresIn}` |
| POST | `/auth/logout` | 退出 | JWT | `{refreshToken}` → `Result` |
| GET | `/user/profile` | 查个人信息 | JWT | → `UserVO` |
| PUT | `/user/profile` | 改昵称/头像 | JWT | `{nickname?, avatar?}` → `Result` |
| PUT | `/user/password` | 改密码 | JWT | `{oldPassword, newPassword}` → `Result` |
| GET | `/user/devices` | 已登录设备 | JWT | → `[{deviceId, loginTime}]` |
| DELETE | `/user/devices/{deviceId}` | 踢下线 | JWT | → `Result` + WS KICK |
| PUT | `/user/ban/{userId}` | 封禁/解禁 | JWT(admin) | `{status: 0\|1}` → `Result` |

## 二、秒杀服务（livemall-seckill）

| 方法 | 路径 | 说明 | 鉴权 | 请求/响应 |
|------|------|------|------|----------|
| POST | `/seckill/activity` | 创建活动 | JWT(admin) | `{title, productId, price, stock, startTime, endTime}` → `ActivityVO` |
| PUT | `/seckill/activity/{id}/status` | 上架/下架 | JWT(admin) | `{status}` → `Result` |
| GET | `/seckill/activity/{id}` | 活动详情 | JWT | → `ActivityVO` |
| GET | `/seckill/activity/list` | 活动列表 | JWT | `?page&size` → `PageResult<ActivityVO>` |
| POST | `/seckill/order` | 抢购下单 | JWT | `{activityId}` → `OrderVO`（阻塞等待 Kafka 结果） |
| GET | `/seckill/order/list` | 我的订单 | JWT | `?page&size` → `PageResult<OrderVO>` |
| GET | `/seckill/order/{orderNo}` | 订单详情 | JWT | → `OrderVO` |
| PUT | `/seckill/order/{orderNo}/cancel` | 取消订单 | JWT | → `Result` |
| PUT | `/seckill/order/{orderNo}/refund` | 退款 | JWT | → `Result` |

## 三、WebSocket（livemall-websocket）

| 协议 | 端点 | 说明 | 鉴权 |
|------|------|------|------|
| WS | `/ws/live/{roomId}` | 直播连接 | Query: `?token=<AccessToken>` |

**连接后消息类型：**

| 方向 | type | data | 说明 |
|------|------|------|------|
| 客户端→服务端 | PING | `{}` | 心跳 |
| 客户端→服务端 | BARRAGE | `{messageId, content}` | 发送弹幕（messageId 用于幂等去重）|
| 客户端→服务端 | GIFT | `{giftId, quantity}` | 送礼 |
| 服务端→客户端 | PONG | `{}` | 心跳回复 |
| 服务端→客户端 | BARRAGE | `{userId, content, timestamp}` | 弹幕广播 |
| 服务端→客户端 | GIFT | `{userId, giftName, quantity}` | 礼物特效 |
| 服务端→客户端 | SEC_KILL_RESULT | `{orderNo, success, msg}` | 秒杀结果 |
| 服务端→客户端 | KICK | `{reason}` | 踢下线 |
| 服务端→客户端 | ONLINE_COUNT | `{count}` | 在线人数更新 |
| 服务端→客户端 | BAN | `{}` | 账号封禁 |

## 四、排行榜服务（livemall-leaderboard）

| 方法 | 路径 | 说明 | 鉴权 | 请求/响应 |
|------|------|------|------|----------|
| GET | `/leaderboard/top` | Top N | JWT | `?activityId&top=100` → `[{rank, userId, score}]` |
| GET | `/leaderboard/rank/{userId}` | 个人排名 | JWT | `?activityId` → `{rank, score}` |
| GET | `/leaderboard/history` | 历史排行 | JWT | `?activityId&time` → `[{rank, userId, score}]` |

> ⚠️ **P1-1 fixed**：`POST /leaderboard/score` 已从 HTTP 接口文档移除。加分走 Dubbo RPC（`LeaderboardService.addScore`），不对外暴露 HTTP——送礼/观看/点赞由 WebSocket 服务通过 Dubbo 触发加分，保证实时性（RPC < 5ms vs Kafka 几百 ms）。

## 五、通用说明

### 统一返回格式

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1719360000000
}
```

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录/Token 过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 429 | 限流 |
| 500 | 服务端错误 |

### 鉴权方式

| 级别 | 说明 |
|------|------|
| 签名 | HMAC-SHA256(Timestamp + Nonce + Secret)，走 `X-Timestamp`、`X-Nonce`、`X-Sign` Header |
| JWT | `Authorization: Bearer <AccessToken>` |
| 内部签名 | 服务间调用使用 Dubbo，无需 HTTP 鉴权 |

### 全局 Header

| Header | 说明 | 适用接口 |
|--------|------|---------|
| X-Timestamp | Unix 毫秒时间戳 | 签名接口 |
| X-Nonce | 随机字符串，60s 去重 | 签名接口 |
| X-Sign | HMAC-SHA256 签名 | 签名接口 |
| Authorization | Bearer + JWT | 鉴权接口 |

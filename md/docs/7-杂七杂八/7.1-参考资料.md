## 二、行业参考

- **秒杀架构**：淘宝双 11 秒杀系统设计（Redis 库存分片 + MQ 削峰）
- **直播互动**：抖音直播弹幕架构（WebSocket 长连接 + 跨节点路由）
- **实时排行榜**：微博热搜榜设计（Redis ZSet + 定时快照 + 冷热分离）
- **双 Token**：微信/支付宝 API 鉴权设计（Access + Refresh 模式）
- **多级缓存**：Caffeine（L1）+ Redis（L2）+ MySQL（L3）是业界标准做法
- **大厂技术博客**：
  - 阿里中间件团队博客：`github.com/alibaba/Sentinel/wiki`（Sentinel 生产实践）
  - 美团技术博客：`tech.meituan.com`（秒杀系统、缓存架构）
  - 字节跳动技术博客：`juejin.cn/user/byteDance`（WebSocket 百万连接实践）
  - Kafka 权威指南（O'Reilly）—— 分层存储、KRaft 模式

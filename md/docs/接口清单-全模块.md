# LiveMall 全模块接口清单

> 测试顺序：用户 → 直播 → 秒杀 → 排行榜 → WebSocket 消息

---

## 一、用户服务（livemall-user）— /auth + /user

### 1.1 注册
```
POST /auth/register
Headers: Content-Type: application/json
         X-Idempotency-Key: test-key-001 (可选，防重复提交)
Body:   {"username":"testuser","password":"Test1234","phone":"13800138000"}
Response: {"code":200,"message":"成功","data":null}
```
**学习点：** `AuthController.register()` → `IdempotencyService.tryAcquire()` → `UserService.preRegister()` BCrypt 加盐 → `UserService.register()` 幂等 SETNX + INSERT

### 1.2 登录
```
POST /auth/login
Headers: Content-Type: application/json
         X-Device-Id: device-uuid-001
Body:   {"username":"testuser","password":"Test1234"}
Response: {"code":200,"data":{"accessToken":"eyJ...","refreshToken":"rft_...","expiresIn":900}}
```
**学习点：** `UserService.login()` → BCrypt 验密 → `JwtUtil.generate()` → Redis 存 refresh + device session

### 1.3 刷新 Token
```
POST /auth/refresh
Body:   {"refreshToken":"rft_..."}
Response: {"code":200,"data":{"accessToken":"eyJ...","refreshToken":"rft_new...","expiresIn":900}}
```
**学习点：** `UserService.refresh()` → 并发合并 CompletableFuture + 分布式锁 SETNX + Rotation

### 1.4 退出登录
```
POST /auth/logout
Body:   {"refreshToken":"rft_..."}
Response: {"code":200}
```
**学习点：** `UserService.logout()` → Redis 删 refresh + 删 device session

### 1.5 个人信息
```
GET /user/profile
Headers: Authorization: Bearer {accessToken}
        X-User-Id: 1
Response: {"code":200,"data":{"id":1,"username":"testuser","nickname":"测试","role":1}}
```
**学习点：** `UserService.findById()` → 查 DB

### 1.6 设备列表
```
GET /user/devices
Headers: Authorization: Bearer {accessToken}
        X-User-Id: 1
Response: {"code":200,"data":[{"deviceId":"d1","current":true}]}
```
**学习点：** `UserService.getDevices()` → Redis SMEMBERS

### 1.7 踢设备下线
```
DELETE /user/devices/{deviceId}
Headers: Authorization: Bearer {accessToken}
        X-User-Id: 1
Response: {"code":200}
```
**学习点：** `UserService.kickDevice()` → Redis SREM + Dubbo WsPushService.kickDevice

## 二、直播服务（livemall-websocket）— /live + WebSocket

### 2.1 HTTP 接口

| 方法 | 路径 | 说明 | 鉴权 |
|---|---|---|---|
| POST | `/live/room/start` | 开播 | 主播/管理员 |
| POST | `/live/room/stop` | 关播 | 主播本人 |
| GET | `/live/rooms` | 首页直播列表 | 公开 |
| GET | `/live/room/{roomId}` | 直播间信息 | 公开 |
| GET | `/live/my-active-room` | 我当前直播 | JWT |

```
POST /live/room/start
Headers: X-User-Id: 1, X-User-Role: 2
Body:   {"title":"测试直播间","category":"digital","coverColor":"linear-gradient(...)"}
Response: {"code":200,"data":{"id":1,"title":"...","status":1,"onlineCount":0}}

POST /live/room/stop
Headers: X-User-Id: 1, X-User-Role: 2
Body:   {"roomId":1}
Response: {"code":200}
```

### 2.2 WebSocket 消息

**连接：** `ws://localhost:8083/ws/live/{roomId}?token={accessToken}`

| 方向 | type | data | 说明 |
|---|---|---|---|
| 客户端→服务端 | `PING` | `{}` | 心跳 |
| 客户端→服务端 | `BARRAGE` | `{"content":"666"}` | 弹幕 |
| 客户端→服务端 | `GIFT` | `{"giftId":1,"quantity":1}` | 送礼 |
| 客户端→服务端 | `AUTH` | `{"token":"eyJ..."}` | 匿名用户升级认证 |
| 客户端→服务端 | `SEC_KILL` | `{"activityId":1}` | WS 秒杀请求 |
| 服务端→客户端 | `PONG` | `{}` | 心跳回复 |
| 服务端→客户端 | `BARRAGE` | `{"userId":1,"nickname":"...","content":"666","timestamp":...}` | 弹幕广播 |
| 服务端→客户端 | `GIFT` | `{"userId":1,"nickname":"...","giftId":1,"quantity":1,"timestamp":...}` | 礼物广播 |
| 服务端→客户端 | `SEC_KILL_RESULT` | `{"orderNo":"...","success":true,"message":"抢购成功","timestamp":...}` | 秒杀结果 |
| 服务端→客户端 | `CONNECTED` | `{"anonymous":false,"displayName":"...","online":86}` | 连接成功 |
| 服务端→客户端 | `AUTH_OK` | `{"userId":1,"role":1,"displayName":"..."}` | 认证升级成功 |
| 服务端→客户端 | `AUTH_FAILED` | `{"reason":"Token 无效"}` | 认证失败 |
| 服务端→客户端 | `NEED_AUTH` | `{"reason":"请先登录"}` | 需要登录 |
| 服务端→客户端 | `KICK` | `{"reason":"..."}` | 被踢 |
| 服务端→客户端 | `ERROR` | `{"reason":"消息格式错误"}` | 错误 |

**弹幕示例：**
```json
// 发送
{"type":"BARRAGE","data":{"content":"冲冲冲"}}
// 收到
{"type":"BARRAGE","data":{"userId":100,"nickname":"user_100","content":"冲冲冲","timestamp":1784426853017}}
```

**礼物示例：**
```json
// 发送
{"type":"GIFT","data":{"giftId":3,"quantity":2}}
// 收到
{"type":"GIFT","data":{"userId":100,"nickname":"user_100","giftId":3,"quantity":2,"timestamp":1784426853017}}
```

## 三、秒杀服务（livemall-seckill）— /seckill

### 3.1 HTTP 接口

| 方法 | 路径 | 说明 | 鉴权 |
|---|---|---|---|
| POST | `/seckill/activity` | 创建秒杀活动 | 管理员 |
| GET | `/seckill/activity/{id}` | 活动详情 | JWT |
| GET | `/seckill/activity/list` | 活动列表 | 公开 |
| POST | `/seckill/order` | **抢购下单** | JWT |
| GET | `/seckill/order/list` | 我的订单 | JWT |
| GET | `/seckill/order/{orderNo}` | 订单详情 | JWT |
| PUT | `/seckill/order/{orderNo}/cancel` | 取消订单 | JWT |
| PUT | `/seckill/order/{orderNo}/refund` | 退款 | JWT |

### 3.2 测试流程（必须按顺序）

```
1. 管理员创建活动
POST /seckill/activity
{"title":"测试秒杀","productId":1,"seckillPrice":99.00,
 "originalPrice":199.00,"totalStock":100,
 "startTime":"2026-07-19T10:00:00","endTime":"2026-07-19T22:00:00"}
→ 返回 activityId=1

2. 需要先把活动状态改为 1（进行中）—— 直接调 DB 或通过 status 接口
UPDATE t_seckill_activity SET status=1 WHERE id=1;

3. 用户抢购
POST /seckill/order
Headers: X-User-Id: 1
{"activityId":1}
→ 返回 "ok" (Lua 扣减成功，已发 Kafka)

4. 查订单
GET /seckill/order/list
Headers: X-User-Id: 1

5. 取消订单
PUT /seckill/order/{orderNo}/cancel
Headers: X-User-Id: 1

6. 退款
PUT /seckill/order/{orderNo}/refund
```

**学习点：**
- `SeckillController.placeOrder()` → `SeckillService.placeOrder()` → `StockService.deduct()` Redis Lua → 成功 → Kafka 发消息
- `SeckillOrderConsumer.onMessage()` → `Thread.startVirtualThread` → `INSERT` → `SeckillPushGrpcService.pushResult()` gRPC 推送到 WebSocket
- `TimeoutCancelScheduler.cancelTimeoutOrders()` → 15s 扫描 → 乐观锁 CAS → 回补库存

## 四、排行榜服务（livemall-leaderboard）— /leaderboard

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/leaderboard/top?activityId=1&n=100` | TopN |
| GET | `/leaderboard/rank/{userId}?activityId=1` | 个人排名 |
| GET | `/leaderboard/history?activityId=1&time=2026-07-19T12:00:00` | 历史排行 |

```
GET /leaderboard/top?activityId=1&n=10
→ {"code":200,"data":[{"userId":100,"score":999.0,"rank":1},...]}

GET /leaderboard/rank/100?activityId=1
→ {"code":200,"data":{"userId":100,"score":999.0,"rank":1}}
```

**学习点：** `LeaderboardServiceImpl` → Redis `ZINCRBY`/`ZREVRANGE`/`ZSCORE`/`ZREVRANK`
送礼触发加分链路：`LiveWebSocket.handleGift()` → Dubbo `LeaderboardService.addScore()` → `ZINCRBY`

## 八、测试快速验证脚本（curl）

```bash
# 1. 注册
curl -X POST http://localhost:8080/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"tester","password":"Test1234"}'

# 2. 登录（保存返回的 accessToken 和 refreshToken）
curl -X POST http://localhost:8080/auth/login \
  -H "Content-Type: application/json" \
  -H "X-Device-Id: test-device-1" \
  -d '{"username":"tester","password":"Test1234"}'

# 3. 个人信息（替换 accessToken）
curl -X GET http://localhost:8080/user/profile \
  -H "Authorization: Bearer {accessToken}" \
  -H "X-User-Id: 1"

# 4. 直播列表
curl http://localhost:8080/live/rooms

# 5. 排行榜 Top10
curl "http://localhost:8080/leaderboard/top?activityId=1&n=10"

# 6. 秒杀下单（替换用户 ID 和活动 ID）
curl -X POST http://localhost:8080/seckill/order \
  -H "Authorization: Bearer {accessToken}" \
  -H "Content-Type: application/json" \
  -H "X-User-Id: 1" \
  -d '{"activityId":1}'
```

## 写作规范

每篇功能文档包含以下章节：

1. **元信息** — 功能编号、归属模块、关联功能与文档
2. **输入输出** — 请求/响应字段级契约 + 每个场景的 code/message
3. **核心流程** — ASCII 流程图
4. **关键代码** — 控制层 / 服务层核心逻辑（非全量）
5. **数据库与 Redis** — 涉及的所有操作
6. **边界处理** — 每个边界场景的输入 → 预期行为
7. **安全点** — 安全相关措施 + 🤔 面试扩展

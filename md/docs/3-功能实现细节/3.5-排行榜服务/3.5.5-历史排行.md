## 输入输出

**请求** `GET /leaderboard/history?activityId=1&time=2026-06-27T12:00:00`（需 JWT）

**响应**

```json
{"code": 200, "data": [{"rank": 1, "userId": 1001, "score": 999.5, "snapshotTime": "2026-06-27T12:00:00"}, ...]}
```

## 核心流程

```sql
SELECT user_id, score, rank, snapshot_time
FROM t_leaderboard_snapshot
WHERE activity_id = ? AND snapshot_time BETWEEN ? AND ?
ORDER BY snapshot_time ASC, rank ASC
LIMIT 100;
```

## 边界处理

| 场景 | 行为 |
|------|------|
| 指定时间无快照 | 查找最近一次快照 |
| 活动不存在 | 空列表 |
| 活动结束后太久 | 数据可能已归档（按月分表）|

🤔 **面试扩展**：历史排行通过 `GROUP BY snapshot_time` 可获取所有快照时间点，前端画折线图展示排名变化趋势。`idx_activity_time` 索引保证查询效率。

## 异常体系

```java
public class BaseException extends RuntimeException {
    protected int code;
    protected String message;
}

public class BizException extends BaseException {
    // 业务异常，code = 1001~1014
}

public class GlobalExceptionHandler {
    @ExceptionHandler(BizException.class)
    public Result<?> handleBiz(BizException e) {
        return Result.error(e.getCode(), e.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<?> handleValidation(MethodArgumentNotValidException e) {
        return Result.error(400, e.getBindingResult().getFieldError().getDefaultMessage());
    }

    @ExceptionHandler(Exception.class)
    public Result<?> handleUnknown(Exception e) {
        log.error("Unexpected error", e);
        return Result.error(500, "服务器内部错误");
    }
}
```

## 统一返回格式

```json
{"code": 200, "message": "success", "data": {}, "timestamp": 1719360000000}
```

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录/Token 过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 429 | 限流 |
| 500 | 服务端错误 |
| 1001~1014 | 业务错误（见 2.1-公共模块.md）|

## 边界处理

| 场景 | 行为 |
|------|------|
| 参数校验失败 | 400 + 具体字段错误 |
| NullPointerException | 500，日志堆栈，不暴露细节 |
| 数据库连接失败 | 500 |
| 未知异常 | 500 + 通用提示 |

🤔 **面试扩展**：`@RestControllerAdvice` 全局捕获，避免每个 Controller 写 try-catch。500 错误不返回堆栈给客户端（安全隐患），只记录日志。业务异常 code 1001~1014 区分具体场景，客户端可根据 code 做不同处理。

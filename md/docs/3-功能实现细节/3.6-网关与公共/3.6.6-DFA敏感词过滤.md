## 核心实现

```java
public class DfaFilter {
    private static class TrieNode {
        Map<Character, TrieNode> children = new ConcurrentHashMap<>();
        boolean isEnd = false;
    }

    private final TrieNode root = new TrieNode();

    public void addWord(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            node = node.children.computeIfAbsent(c, k -> new TrieNode());
        }
        node.isEnd = true;
    }

    public String replaceSensitiveWords(String text, char replacement) {
        StringBuilder result = new StringBuilder(text);
        int i = 0;
        while (i < text.length()) {
            TrieNode node = root;
            int j = i;
            while (j < text.length() && node.children.containsKey(text.charAt(j))) {
                node = node.children.get(text.charAt(j));
                j++;
                if (node.isEnd) {
                    for (int k = i; k < j; k++) {
                        result.setCharAt(k, replacement);
                    }
                    break;
                }
            }
            i++;
        }
        return result.toString();
    }
}
```

## 核心流程

```
敏感词库加载（初始化 / Nacos 动态更新）
  → 构建 Trie 树
  → replaceSensitiveWords(content, '*')
  → 时间复杂度 O(N)，N 为内容长度
```

## 边界处理

| 场景 | 行为 |
|------|------|
| 无敏感词 | 原样返回 |
| 内容中有多个敏感词 | 全部替换 |
| 敏感词重叠（如"abc"和"ab"）| 优先匹配最长 |
| 短文本（1 字符）| 正常匹配 |
| 空文本 | 原样返回 |

🤔 **面试扩展**：为什么用 DFA（Trie）而不是正则？DFA 时间复杂度 O(N) 线性，正则在最坏情况下 O(2^N)。敏感词库通常 10w+ 条，Trie 树可以全量加载到内存。Nacos 动态更新词库无需重启。并发安全用 ConcurrentHashMap 保证。

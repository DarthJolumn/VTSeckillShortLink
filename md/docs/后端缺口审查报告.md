### 缺口 3: 钱包/余额

**设计：**
- `t_user` 加 `balance DECIMAL(15,2) DEFAULT 8888.00`
- 送礼时：查余额 → 扣款 → 失败返回余额不足
- 充值：暂不做，初始给 8888

**方案：**
```java
// UserService
@Transactional
public void deductBalance(Long userId, BigDecimal amount) {
    User user = findById(userId);
    if (user.getBalance().compareTo(amount) < 0) {
        throw new BizException(1015, "余额不足");
    }
    user.setBalance(user.getBalance().subtract(amount));
    userMapper.updateById(user);
}

public BigDecimal getBalance(Long userId) {
    return findById(userId).getBalance();
}
```

**工作量：** User 实体加字段 + DB 加列 + 2 个接口 + LiveWebSocket.handleGift 调扣款

### 缺口 4: 秒杀活动关联直播间

**方案：**
- `SeckillActivity` 加 `roomId` 字段
- 创建活动时传入 `roomId`
- `GET /seckill/activity/list?roomId=1` 支持按直播间过滤

**工作量：** DB 加列 + 实体加字段 + Repository 加方法 + Controller query param

## 四、实现优先级

| 优先级 | 内容 | 理由 |
|---|---|---|
| P0 | 秒杀活动→直播间关联 (`roomId`) | LiveRoom.vue 显示实时活动需要 |
| P0 | 钱包余额 + 扣款 | 送礼扣钱是核心闭环 |
| P1 | GET /user/list | 管理后台 |
| P1 | PUT /user/role/{userId} | 管理后台 |
| P2 | 直播复盘/统计 | 低优先级 |

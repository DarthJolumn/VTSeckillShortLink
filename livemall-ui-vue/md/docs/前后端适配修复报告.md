| 问题编号 | 问题 | 修复方式 | 影响文件 |

### 2.12 前端新增 — `composables/useThrottle.js`

## 三、修复前后对比

| 场景 | 修复前 | 修复后 |
|---|---|---|
| 真后端弹幕广播 | 用户名一列为空（`nickname`↔`username`） | 正常显示 |
| 真后端秒杀 | WS `SEC_KILL` 只打日志，无响应 | REST `/seckill/order` → Kafka → gRPC 推送结果 |
| 创建活动 | 字段全 null 入库 | `CreateActivityRequest` DTO 正确转换 |
| 修改资料/密码/封禁 | 接口 404 | 正常调用 |
| 弹幕/送礼重复发送 | 无防护，网络抖动会重复 | WS 层 500ms 去重 |
| 写操作幂等 | 从不传 `X-Idempotency-Key` | 自动注入 UUID |
| Mock 开关 | `lm_refresh` 隐式判断（演示登录会触发矛盾） | `VITE_MOCK_MODE` 环境变量一刀切 |

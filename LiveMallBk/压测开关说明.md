# 压测开关说明

## 下次压测前需要改 3 处

### 1. `application.yml:113` — 关掉超时取消
```
timeout-cancel-enabled: true  →  false
```

### 2. `application.yml:121` — 关掉 Redis 防重复下单（否则同一用户只能下一单）
```
dedup-enabled: true  →  false
```

### 3. `application.yml:23` — 加大 HikariCP（配合加大并发）
```
hikari.maximum-pool-size: 30  →  60
```

### 4. `application.yml:123` — 加大消费者并发（必须 <= HikariCP）
```
consumer-max-concurrency: 30  →  60
```

## 压测跑完后恢复原值（上面 4 处改回来）
- `timeout-cancel-enabled` → `true`
- `dedup-enabled` → `true`
- `hikari.maximum-pool-size` → `30`
- `consumer-max-concurrency` → `30`

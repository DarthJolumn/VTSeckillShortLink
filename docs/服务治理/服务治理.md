# LiveMall 服务治理

> 跨服务通信记录（Dubbo + gRPC + Kafka + 网关转发）

---

        │ RPC

---

## 1. `UserDubboApi` — 用户信息查询

| 角色 | 模块 | 实现/消费 |
|------|------|----------|
| **Provider** | `livemall-user` | `UserDubboApiImpl` (`@DubboService`) |
| **Consumer** | `livemall-websocket` | 开播时查主播昵称、session 升级查用户 |
| **Consumer** | `livemall-seckill` | （预留）秒杀时验证用户身份 |
| **Consumer** | `livemall-leaderboard` | 排行榜展示用户昵称/头像 |

- **接口**: `com.jolumn.livemallcommon.api.UserDubboApi`
- **方法**: `getById(userId)`, `getByUsername(username)`
- **Provider 端口**: `dubbo.protocol.port=20881`

---

## 2. `WsPushService` — WebSocket 推送

| 角色 | 模块 | 实现/消费 |
|------|------|----------|
| **Provider** | `livemall-websocket` | `WsPushServiceImpl` (`@DubboService`) |
| **Consumer** | `livemall-user` | 踢设备下线时推送踢人通知 |

- **接口**: `com.jolumn.livemallcommon.api.WsPushService`
- **方法**: `push` / `pushToRoom` / `kickUser` / `kickDevice`
- **调用方配置**: `dubbo.consumer.check=false`

---

## 3. `LeaderboardService` — 排行榜

| 角色 | 模块 | 实现/消费 |
|------|------|----------|
| **Provider** | `livemall-leaderboard` | Dubbo 服务 |
| **Consumer** | `livemall-websocket` | 送礼时 `addScore()` |

- **接口**: `com.jolumn.livemallcommon.api.LeaderboardService`
- **方法**: `addScore` / `getTopN` / `getRank` / `getHistory`

---

## 4. gRPC 服务 — `SeckillPush`

| 角色 | 模块 | 说明 |
|------|------|------|
| **Provider** | `livemall-websocket` | `SeckillPushGrpcService` (port 9090) |
| **Consumer** | `livemall-seckill` | 秒杀完成后推送结果到 WS 节点 |

**proto**: `seckill-push.proto` (`com.jolumn.livemallcommon.grpc`)
```protobuf
rpc PushResult(SeckillPushRequest) returns (SeckillPushResponse)
```
- seckill 通过 `GrpcClientConfig` 配置 WS 地址: `seckill.grpc.websocket-host/port`

---

## 5. Kafka 消息

| 主题 | 生产者 | 消费者 | 说明 |
|------|--------|--------|------|
| `seckill-order` | livemall-seckill | livemall-seckill (group: `livemall-seckill`) | 抢购成功异步下单，4 个并发消费线程 |
| `seckill-order-result` | livemall-seckill | livemall-websocket (group: `livemall-ws`) | （预留）秒杀结果异步推送 |

---

## 6. 网关路由（Spring Cloud Gateway）

| 路由 | 目标服务 | 路径 | 协议 |
|------|---------|------|------|
| user-service | livemall-user | `/auth/**`, `/user/**` | HTTP |
| seckill-service | livemall-seckill | `/seckill/**` | HTTP |
| leaderboard-service | livemall-leaderboard | `/leaderboard/**` | HTTP |
| live-service | livemall-websocket | `/live/**` | HTTP |
| websocket-service | livemall-websocket | `/ws/**` | WebSocket |

## 7. 服务间依赖汇总

| 消费者 | 提供者 | 协议 | 接口/服务 |
|--------|--------|------|----------|
| livemall-gateway | livemall-user | HTTP (Gateway) | `/auth/**`, `/user/**` |
| livemall-gateway | livemall-seckill | HTTP (Gateway) | `/seckill/**` |
| livemall-gateway | livemall-leaderboard | HTTP (Gateway) | `/leaderboard/**` |
| livemall-gateway | livemall-websocket | HTTP / WS | `/live/**`, `/ws/**` |
| livemall-user | livemall-websocket | Dubbo | `WsPushService.kickDevice()` |
| livemall-websocket | livemall-user | Dubbo | `UserDubboApi.getById()` |
| livemall-websocket | livemall-leaderboard | Dubbo | `LeaderboardService.addScore()` |
| livemall-seckill | livemall-websocket | gRPC | `SeckillPush.PushResult()` |
| livemall-seckill | livemall-websocket | Kafka (预留) | `seckill-order-result` |
| livemall-seckill | — | Kafka (内部) | `seckill-order` |

# 公共模块 — livemall-common

**包名**: `com.jolumn.livemallcommon` | **打包方式**: jar（无独立进程）

> 所有服务共享的基础库，包含 Dubbo API、DTO、工具类、异常体系、注解等。

---

## 1. 认证注解体系

### `@PublicApi`
- 标记接口无需任何鉴权，任何人可访问
- `AuthInterceptor` 跳过处理
- 使用场景: 公开的直播间信息、活动列表

### `@RequireAuth`
- 标记接口需要登录（任意角色）
- `AuthInterceptor` 校验 `X-User-Id` 非空
- 使用场景: 个人资料、订单列表

### `@RequireRole({RoleEnum.ANCHOR, RoleEnum.ADMIN})`
- 标记接口需要特定角色
- `AuthInterceptor` 校验角色在允许列表中
- 使用场景: 开播（主播/管理员）、封禁（管理员）

### 执行流程

```
Gateway JwtAuthGlobalFilter   (WebFlux 层)
  → 注入 X-User-Id / X-User-Role Header
  → 路由到下游 MVC 服务

MVC AuthInterceptor           (Servlet 层)
  → 根据注解策略鉴权
  → 设备在线检查（Redis SISMEMBER）
  → 返回 401/403 或放行
```

## 2. 上下文 — `UserContext`

基于 JDK 25 `ScopedValue` 的线程上下文：

| 字段 | 类型 | 说明 |
|------|------|------|
| `USER_ID` | `ScopedValue<Long>` | 当前用户 ID |
| `ROLE` | `ScopedValue<Integer>` | 当前角色 |
| `DEVICE_ID` | `ScopedValue<String>` | 当前设备 ID |

## 4. DTO

### `Result<T>`
统一响应体: `{code, message, data, timestamp}`
- `Result.ok(data)` — 200
- `Result.error(code, message)` — 自定义错误

### `PageResult<T>`
分页响应: `{records, total, page, size, totalPages}`

### `UserDTO`
Dubbo 跨服务用户信息: id / username / nickname / avatar / role / status

### `RankEntry`
排行榜条目: userId / score / rank

## 6. 工具类

### `JwtUtil`
- `generate(userId, role, ttlSeconds)` → JWT
- `parse(token)` → `Claims`
- HMAC-SHA256 签名，Base64 secret

### `HmacUtil`
- `sha256(data, secret)` → 十六进制 HMAC-SHA256 签名

### `IdempotencyService`
- `tryAcquire(key)` — SETNX 5min
- `get/set` — 缓存 JSON 序列化结果
- Redis 不可用时降级放行

### `SnowflakeIdGenerator`
- `nextId()` → 分布式唯一 ID
- `nextOrderNo()` → 订单号
- 1+41+10+12 位，workerId 可配
- `ReentrantLock` 防并发，时钟回拨保护 ≤30ms

## 7. 异常体系

```
RuntimeException
  └─ BaseException (code + message)
       └─ BizException (业务异常)
```

### `GlobalExceptionHandler`
| 异常 | HTTP 状态码 | 说明 |
|------|------------|------|
| `BizException` | 动态 | 业务异常（code 由业务定义） |
| `MethodArgumentNotValidException` | 400 | 参数校验失败 |
| `HttpMessageNotReadableException` | 400 | 请求体格式错误 |
| `MissingRequestHeaderException` | 400 | 缺少必填 Header |
| `Exception` | 500 | 未知异常 |

> Gateway 有独立的 `GlobalErrorWebExceptionHandler`（WebFlux），不共享此 Handler。

# 排行榜服务 — livemall-leaderboard

**端口**: 8084 | **Dubbo**: 20884 | **存储**: Redis ZSet + MySQL 快照

---

## 1. 互动加分 — `LeaderboardService.addScore()` (Dubbo)

由 `livemall-websocket` 通过 Dubbo 调用，送礼时加分。

**权重表**:

| 事件类型 | 权重分值 |
|---------|---------|
| WATCH | 0.3 |
| LIKE | 0.5 |
| COMMENT | 1.0 |
| SHARE | 2.0 |
| GIFT | 5.0 |

实现: `redisTemplate.opsForZSet().incrementScore("leaderboard:" + activityId, userId, weight)`

---

## 2. REST 接口

所有接口均公开（Gateway `public-get-paths` 放行 GET 请求）。

### 2.1 实时 TopN `GET /leaderboard/top`

| 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|
| `activityId` | 是 | — | 活动 ID |
| `n` | 否 | 100 | 返回前 N 名 |

**响应**: `List<RankEntry>`（userId / score / rank）

实现: `ZREVRANGE leaderboard:{activityId} 0 N-1 WITHSCORES`

### 2.2 个人排名 `GET /leaderboard/rank/{userId}`

| 参数 | 必填 |
|------|------|
| `activityId` | 是 |

**响应**: `RankEntry`（score + rank，未参与返回 rank=-1）

实现: `ZSCORE` + `ZREVRANK`

### 2.3 历史排行 `GET /leaderboard/history`

| 参数 | 必填 | 默认 |
|------|------|------|
| `activityId` | 是 | — |
| `time` | 否 | now |

> 暂空实现（`List.of()`），等待快照数据累积。

## 3. TopN 本地缓存

Caffeine 1s 缓存 `leaderboard.getTopN()` 结果，降低 Redis 读压力：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `leaderboard.topn-cache.ttl-seconds` | 1 | 缓存时间 |
| `leaderboard.topn-cache.max-size` | 1000 | 最大条目数 |

---

## 4. 定时快照 — `SnapshotScheduler`

每 5 分钟将 Redis ZSet Top 100 落库到 `t_leaderboard_snapshot`。

```
@Scheduled(cron = "0 */5 * * * ?")
  → SCAN "leaderboard:*"
  → ZREVRANGE key 0 99 WITHSCORES
  → 批量 INSERT t_leaderboard_snapshot
```

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `leaderboard.snapshot.cron` | `0 */5 * * * ?` | 快照频率 |
| `leaderboard.snapshot.top-n` | 100 | 每次取前 N |
| `leaderboard.snapshot.batch-size` | 500 | 批量 INSERT 大小 |

## 5. 数据模型

### t_leaderboard_snapshot

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT (Auto) | 主键 |
| `activity_id` | BIGINT | 活动 ID |
| `user_id` | BIGINT | 用户 ID |
| `score` | DECIMAL(15,2) | 分值 |
| `rank` | INT | 排名 |
| `snapshot_time` | DATETIME | 快照时间点 |
| `created_at` | DATETIME | 创建时间 |

## 7. 数据流

```
送礼 WS → LiveWebSocket.handleGift()
  → Dubbo LeaderboardService.addScore()
  → Redis ZINCRBY
  → (客户端轮询/WS推送) GET /leaderboard/top
  → Caffeine L1 → 无缓存则 ZREVRANGE
  → 每 5min SnapshotScheduler 落库
  → 历史排行查询
```

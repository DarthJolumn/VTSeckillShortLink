## 一、用户服务（livemall-user）

### 1.1 注册

```
POST /auth/register
Headers: Content-Type: application/json
         X-Idempotency-Key: test-key-001 (可选，防重复提交)
Body:   {"username":"testuser","password":"Test1234","phone":"13800138000"}
Response: {"code":200,"message":"成功","data":null}
```

**链路：** `AuthController.register()` → `IdempotencyService.tryAcquire()` → `UserService.preRegister()` BCrypt 加盐 → `UserService.register()` 幂等 SETNX + INSERT

```bash
curl -X POST http://localhost:8080/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"test01","password":"Test1234"}'
```

- [ ] 🔲 正常注册 → `{"code":200}`
- [ ] 🔲 重复注册同一 username → `{"code":1012,"message":"用户名已被注册"}`
- [ ] 🔲 username 长度 < 4 → 400
- [ ] 🔲 password 长度 < 8 → 400
- [ ] 🔲 带 X-Idempotency-Key 重复请求 → 幂等返回 200，DB 只一条数据

### 1.2 登录

```
POST /auth/login
Headers: Content-Type: application/json
         X-Device-Id: device-uuid-001
Body:   {"username":"testuser","password":"Test1234"}
Response: {"code":200,"data":{"accessToken":"eyJ...","refreshToken":"rft_...","expiresIn":900}}
```

**链路：** `UserService.login()` → BCrypt 验密 → `JwtUtil.generate()` → Redis 存 refresh + device session

```bash
curl -X POST http://localhost:8080/auth/login \
  -H "Content-Type: application/json" \
  -H "X-Device-Id: device-001" \
  -d '{"username":"test01","password":"Test1234"}'
```

- [ ] 🔲 正确密码 → `{"accessToken":"...","refreshToken":"rft_...","expiresIn":900}`
- [ ] 🔲 accessToken 可 JWT 解码含 userId + role + exp
- [ ] 🔲 错误密码 → `{"code":1011,"message":"用户名或密码错误"}`
- [ ] 🔲 缺少 X-Device-Id → 400
- [ ] 🔲 封禁用户登录 → `{"code":1006}`

### 1.3 刷新 Token

```
POST /auth/refresh
Body:   {"refreshToken":"rft_..."}
Response: {"code":200,"data":{"accessToken":"eyJ...","refreshToken":"rft_new...","expiresIn":900}}
```

**链路：** `UserService.refresh()` → 并发合并 CompletableFuture + 分布式锁 SETNX + Rotation

```bash
curl -X POST http://localhost:8080/auth/refresh \
  -H "Content-Type: application/json" \
  -d '{"refreshToken":"rft_..."}'
```

- [ ] 🔲 合法 refreshToken → 返回新 accessToken + 新 refreshToken
- [ ] 🔲 旧 refreshToken 已删除（Rotation）
- [ ] 🔲 旧 refreshToken 再次 refresh → `{"code":1013,"message":"登录已过期"}`
- [ ] 🔲 并发 5 个线程同时 refresh → 只签发一次新 token（合并请求）

### 1.4 退出登录

```
POST /auth/logout
Body:   {"refreshToken":"rft_..."}
Response: {"code":200}
```

**链路：** `UserService.logout()` → Redis 删 refresh + 删 device session

```bash
curl -X POST http://localhost:8080/auth/logout \
  -H "Content-Type: application/json" \
  -d '{"refreshToken":"rft_..."}'
```

- [ ] 🔲 退出后 Redis 中 refresh key 已删除
- [ ] 🔲 退出后用旧 refreshToken 刷新 → 1013
- [ ] 🔲 空 refreshToken → 400

- [ ] 🔲 带过期 token → 401
- [ ] 🔲 正确 token → 放行，下游收到 X-User-Id / X-User-Role 头
- [ ] 🔲 /auth/login + 正确签名字段 → 放行
- [ ] 🔲 错误签名字段 → 401 "Invalid signature"
- [ ] 🔲 过期 timestamp → 401 "Timestamp expired"
- [ ] 🔲 重复 nonce → 401 "Nonce reused"

## 附录：快速验证脚本

```bash
# 1. 注册
curl -X POST http://localhost:8080/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"tester","password":"Test1234"}'

# 2. 登录（保存返回的 accessToken 和 refreshToken）
curl -X POST http://localhost:8080/auth/login \
  -H "Content-Type: application/json" \
  -H "X-Device-Id: test-device-1" \
  -d '{"username":"tester","password":"Test1234"}'

# 3. 个人信息（替换 accessToken）
curl -X GET http://localhost:8080/user/profile \
  -H "Authorization: Bearer {accessToken}" \
  -H "X-User-Id: 1"

# 4. 直播列表
curl http://localhost:8080/live/rooms

# 5. 排行榜 Top10
curl "http://localhost:8080/leaderboard/top?activityId=1&n=10"

# 6. 秒杀下单（替换用户 ID 和活动 ID）
curl -X POST http://localhost:8080/seckill/order \
  -H "Authorization: Bearer {accessToken}" \
  -H "Content-Type: application/json" \
  -H "X-User-Id: 1" \
  -d '{"activityId":1}'
```
